# Gate spec: S2.4b Excel MCP daemon wiring

The Boss writes this spec. A **different worker from the implementer** writes `scripts/verify_s2_4b.py` from it,
without reading `tests/test_mcp_excel_daemon.py`, so the gate stays independent. The Boss runs the gate.

## What the packet claims

`src/harness/mcp/excel_server.py` recalculates workbooks through `om.recalc.compare`, and reports the state of the
recalculation engines honestly, including when LibreOffice is not usable.

## Assertions the gate must prove

Each assertion must be a real check against real output, not a re-run of the unit tests.

### A. The wiring is real

1. `xlsx_recalc` on a real generated model returns `available: true` and a report containing `agree`, `engines`,
   `divergences` and `compared_cells`.
2. `compared_cells` is greater than 500 for the standard synthetic model, so the tool is not returning an empty
   report that trivially "agrees".
3. The report's `engines` keys are exactly `om.recalc.DEFAULT_ENGINES`. A missing engine must appear as a key with
   `available: false` and a non-empty `reason`, never be silently absent.
4. **Adversarial:** plant a wrong cached value in a known formula cell and assert the tool reports that exact cell
   in `divergences` with the planted delta. A tool that always says `agree: true` must fail here.
5. **Adversarial:** `xlsx_recalc` with `engines=["cached", "om"]` must compare only those two, and must still find
   the planted divergence. This proves the `engines` argument is honoured and not ignored.
6. **Adversarial:** an unknown engine name must raise a tool failure, not be silently dropped.
7. **Adversarial:** a path outside `ACRETIA_MCP_ROOT` must be refused, and a missing file must raise a tool
   failure rather than crash the server.

### B. The old bug is gone

8. Assert that `om.recalc` exposes none of `recalc_file`, `recalculate`, `three_engine`, `check`. This documents
   why the old implementation could never work, and fails if someone reintroduces a guessed entry point.
9. Assert that `xlsx_recalc` does not contain the string `"exposes no recalc entry point"` in its source, so the
   dead branch cannot come back.

### C. Engine status is honest

10. `xlsx_engine_status` returns every engine in `DEFAULT_ENGINES` with `available` and `reason` on each.
11. `om` and `cached` are always `available: true`.
12. `ready` is true exactly when at least two engines are available.
13. Every engine reporting `available: false` has a non-empty `reason` that names its dependency (`uno`, `soffice`
    or `formulon`). An unavailable engine with an empty reason must fail the gate.
14. **Adversarial:** calling `xlsx_engine_status` must not increase `recalc.daemon().starts`. Asking about the
    engine must not spawn a process.

### D. Restart is safe

15. `xlsx_engine_restart` returns a status and leaves `xlsx_recalc` working afterwards.
16. When LibreOffice is unavailable, restart must still return `available: true` with the reason recorded, not
    raise. The gate must run this path on this machine, where the bridge is missing.
17. When LibreOffice **is** available, restart must change the daemon pid and recalculation must still agree. The
    gate must skip this with a printed reason when the bridge is missing, and must not report a pass it did not
    earn.

### E. The protocol layer

18. `tools/list` returns all five tools with an `inputSchema` each.
19. `xlsx_engine_status` has `required: []`, so it can be called with no arguments.
20. `xlsx_recalc`'s schema includes the optional `engines` array.
21. A `tools/call` for `xlsx_recalc` returns a JSON payload whose `result.compared_cells` is greater than 500.

### F. No regression

22. `python3 -m unittest tests.test_recalc -q` is green (or skips only for a missing engine).
23. The gate must print, for each engine, whether it was exercised or skipped and why. A gate that silently skips
    LibreOffice and prints "PASS" is not acceptable: it must say `libreoffice: SKIPPED (uno bridge not importable)`.

## Output

The gate prints one line per assertion, `PASS`/`FAIL`/`SKIPPED` with the reason, then a summary count, and exits
non-zero if any assertion failed. It must not need the network and must not make model calls.

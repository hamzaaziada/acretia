## Structure (file:line in the clone, `src/`)

- [OBSERVATION] Agent loop: `Agent.run` (`agent/agent.ts:128`) is a plain tool-calling (ReAct) loop: build messages from the system prompt and history, call the model, run requested tools, repeat until the model answers without tool calls or `maxIterations` (`:149`; final fallback message at `:282`). There is no separate planner, reflection or validator agent at this commit. Context is managed by per-turn `microcompactMessages` (`:153`), "strip old reasoning, keep the last 2" (`:160`), overflow truncation with retries (`:176-189`), and an LLM compaction summary that must keep "ALL key numbers retrieved" (`agent/compact.ts:56`).
- [OBSERVATION] Scratchpad: `agent/scratchpad.ts` writes one JSONL file per query under `.dexter/scratchpad/<timestamp>_<hash>.jsonl` (`:66,97`) with entries `init`, `tool_result` (toolName, args, result, timestamp) and `thinking` (`:11-19`). In my run, four calls produced four `tool_result` lines such as `{"type":"tool_result","timestamp":"2026-11-16T21:45:28.006Z","toolName":"get_financials","args":{"query":"AAPL revenue"},"result":{"revenue":478834000000,"period":"FY2026"}}`.
- [OBSERVATION] Tool-use guard: `canCallTool` (`scratchpad.ts:131`) counts calls per tool (default 3) and compares query similarity (threshold 0.7); in my run it returned `allowed:true` on every call and only added warnings ("very similar to a previous call... 2 attempt(s) before reaching the suggested limit", "called 3 times (suggested limit: 3)"; usage summary "4 calls (over suggested limit of 3)"). The limit is soft by design (`scratchpad.ts:62-63` comment: "warnings, not blocks").
- [OBSERVATION] Skills: `skills/dcf/SKILL.md` (8-step checklist: gather data, FCF growth, WACC with `sector-wacc.md`, project, PV, sensitivity, validate, caveats), `skills/write-memo/` (memo template, style, examples), `skills/x-research/`; loaded by `skills/loader.ts` and described in the system prompt's "Available Skills" section (`agent/prompts.ts:67-80`).
- [OBSERVATION] Finance data tools (`tools/finance/`): `get-financials`, `key-ratios`, `earnings`, `filings`, `read-filings`, `segments`, `insider_trades`, `institutional_holdings`, `screen-stocks` and others, all calling `https://api.financialdatasets.ai` with `FINANCIAL_DATASETS_API_KEY` (`tools/finance/api.ts:4,44`). Not SEC-direct, and paid.
- [OBSERVATION] Sub-agents: `tools/subagent/spawn-subagent.ts`; permissions engine (`permissions/engine.ts`, rules, read-only command checks); memory tools; gateway for WhatsApp; browser (Playwright) tools. 24,452 lines of TypeScript in `src/` by `wc -l`.
- [OBSERVATION] Source logging: only the tool name, arguments, result and timestamp are logged. No source URL or accession number, no as-of date, no hash chain, no "figure to source" check on the final answer; `grep -i source agent/prompts.ts` finds no instruction to cite sources.
- [INFERENCE] PLAN S6.1 says dexter provides "task planning with self-reflection and a source-logged scratchpad". At this commit only the scratchpad and the tool-call limits exist; planning and reflection are left to the model inside the loop and to skill checklists. The JSONL scratchpad is the useful, small idea: an append-only per-query record that survives crashes.
- [INFERENCE] Acretia's evidence bundle (hash-chained JSONL with tool, args hash, source id, page, bbox, output hash) is a strict superset of dexter's scratchpad; borrow the "soft call limits plus similarity warning" and the tool-usage summary injected into the next prompt (`scratchpad.ts:197-240`, `formatToolUsageForPrompt` at `:223`), which stops an agent looping on one failing tool.
- [INFERENCE] TypeScript plus Bun is outside Acretia's Python standard-library core; this can only be ideas.
